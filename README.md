# FreeDoom

Контроль качества диалогов RU / KZ / EN: оценка Gemini, объяснения с привязкой к репликам, аудиоплеер, апелляции и редактор чек-листа.

## Запуск

Python 3.11+, один процесс:

```sh
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Введите ключ Gemini в шапке сайта. Используется строго `gemini-2.0-flash`. Ключ сохраняется в localStorage браузера под `gemini_api_key` и восстанавливается при перезагрузке. Очистка поля очищает сохранённое значение. На сервере ключ используется только для текущего запуска и не попадает в JSON.

## Работа

1. Выберите DEV/PROD и загрузите JSON. Поддерживаются `data.records`, `records` и массив диалогов. Для GET организаторов настройте константу `ORGANIZER_API_URL` в server.py; загрузка файла настройки не требует.
2. При необходимости измените чек-лист: названия, правила, веса, допустимые значения и флаги.
3. «Оценить все» запускает фоновую оценку. Прогресс и готовые карточки обновляются каждые 1,5 секунды. Перезагрузка страницы не останавливает задачу. Сервер должен продолжать работать.
4. Нажмите номер реплики для перехода к ней с подсветкой на 2 секунды. Если задан `audio_url`, доступен плеер; время реплики в формате MM:SS или HH:MM:SS используется для перехода в записи после загрузки метаданных.
5. В режиме «Оператор» нажмите «Оспорить» у критерия и отправьте комментарий. В центре апелляций доступны фильтры ожидающих и рассмотренных обращений.
6. В режиме «Супервизор» откройте центр апелляций: проверьте цитаты, выберите новое значение (или подтвердите прежнее), укажите причину и нажмите «Утвердить». Итог пересчитывается сразу по чек-листу, использованному при оценке.
7. Скачайте results.json после обработки всех диалогов. Проверьте ошибки и количество записей: DEV — 65, PROD — 10. Экспорт сохраняет формат результатов, история пересмотров хранится отдельно в состоянии.

Роли — переключатель интерфейса без авторизации, как предусмотрено для демонстрации. Это не разграничение доступа к API.

## Расчёт и история

Итог = 100 × сумма набранных взвешенных баллов / сумма применимых весов. N/A исключается из знаменателя. Флаги нарушений имеют вес 0 и не обнуляют итог. В `original_ai` неизменно сохраняются исходные ответы, объяснения и балл ИИ. Каждая апелляция сохраняет исходную и предыдущую оценку, комментарий, решение, причину, время и итог после пересмотра. Повторная оценка и новый импорт архивируют прежний набор и историю в `archives`.

## Хранение

- `data/state.json` — диалоги, оценки, апелляции, архивы; восстанавливается при запуске.
- `data/checklist.json` — текущий чек-лист.
- `data/dev_source.json`, `data/prod_source.json` — исходные наборы.
- `results/dev/results.json`, `results/prod/results.json` — результаты для сдачи.

Один server.py и один static/index.html. Без базы данных, .env, внешней очереди или Render. Только память процесса и локальные JSON. Не запускайте несколько workers: состояние общее только внутри одного процесса. При остановке процесса фоновая оценка прерывается; уже готовые результаты сохранены, незавершённый запуск нужно повторить.

## API

- `POST /api/load-data`: JSON `{ "group_id": "DEV", "dataset": [...] }` либо multipart `file`, `group_id`.
- `GET /api/dialogues`: диалоги, результаты, прогресс, апелляции, чек-лист запуска и экспорт.
- `POST /api/evaluate` (также `/api/evaluate-batch`): `{ "api_key": "..." }`; немедленно возвращает `{ "status": "started" }`. Обработка через FastAPI BackgroundTasks.
- `POST /api/checklist`: `{}` читает; `{ "checklist": [...] }` сохраняет.
- `POST /api/appeal`: `conversation_id`, `criterion_id`, `comment`.
- `POST /api/appeal/resolve`: `conversation_id`, `criterion_id`, `new_value`, `reason`.

## Проверка

Проверены возврат HTTP-ответа до завершения фоновой задачи, запрет параллельного запуска, прогресс, отправка и разрешение апелляции, запрет дубликатов, типы оценок, пересчёт с N/A, сохранение исходной оценки и истории на диск, архивирование и отсутствие ключа в состоянии/экспорте. Реальный запрос к Gemini требует рабочего ключа и доступа к указанной модели; точность на DEV пока не измерена.
